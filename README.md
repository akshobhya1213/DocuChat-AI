# DocuChat AI
A lightweight document RAG demo. Upload PDF, DOCX or TXT, then ask independent questions grounded in retrieved passages.

## Local setup
Python 3.12 recommended. Run `pip install -r requirements.txt`. Obtain a Gemini API key from https://aistudio.google.com/apikey and set GEMINI_API_KEY in your environment (PowerShell: `$env:GEMINI_API_KEY="your-key"`). Run `python app.py` and open http://localhost:5000.

## Render
In Render create a Blueprint from the repository, or create a Python Web Service on the Free plan. Build: `pip install -r requirements.txt`. Start: `gunicorn --workers 1 --threads 2 --timeout 180 --bind 0.0.0.0:$PORT app:app`. Set GEMINI_API_KEY and a random SECRET_KEY in Environment. Use one worker because the index is in memory. Model defaults are gemini-embedding-001 and gemini-2.5-flash; override EMBEDDING_MODEL and GENERATION_MODEL if needed. Verify current model availability, free quotas and Render terms before deployment. Never commit API keys.

## Interview explanation
Indexing: extract text, split into 260-word chunks with 40-word overlap, embed chunks with retrieval-document task, normalize and store vectors in NumPy. Query: embed question with retrieval-query task, calculate cosine similarity using normalized dot products, select top four passages, pass them to Gemini with grounding instructions, return answer and retrieved excerpts. RAG does not train or fine-tune the LLM. Retrieval is exact linear search, not a persistent vector database. Chunk overlap preserves context across boundaries. Citations are generated by the LLM and should be checked against displayed excerpts.

## Demo
Upload sample.txt. Ask: What is the refund window? What is the support email? Who founded the company? The last question should be declined because the information is absent. Each question is independent; visible chat history is not sent to the model.

## Limits
8 MB upload, 100 PDF pages, 160 chunks, up to 20 in-memory document sessions, one-hour expiry. Scanned PDFs need OCR; DOCX tables and images are not extracted. Render restarts or idle shutdown lose documents. API requests send text to Google; do not use sensitive documents. Free quotas are not guaranteed. Public deployment has no authentication or rate limiting; keep it a personal demo to avoid quota abuse. Grounding instructions reduce but cannot eliminate hallucinations or prompt injection. No live API or Render deployment has been verified.
